Extension Defense Engines

A multi-layered heuristic stack designed to safeguard browsing sessions without network overhead.

Primary Heuristic Real-Time Core

Typosquatting & IDN Homograph Detection

Analyzes navigation requests against unicode lookalike alphabets (Cyrillic, Greek, Latin substitutions) and Levenshtein distance metrics targeting global financial and SaaS domains.

In Action: Detects and flags deceptive addresses like g00gle.com or punycode clones like xn--pple-43d.com (аррӏе.com) before connection handshakes occur.
Tech Jargon

Plain-English Lexicon

Translates cryptic browser security warnings, protocol downgrade errors, and certificate mismatches into digestible language.

In Action: Explains threats like "Man-in-the-Middle" or "Cross-Site Scripting" in plain terms without technical jargon.
Form Guard

Insecure Form Protection

Monitors DOM input fields on unencrypted HTTP endpoints or pages submitting credentials to non-matching origin domains.

In Action: Intercepts submit triggers on plaintext login forms before your password transmits over unencrypted networks.
Privacy Engine

Tracking Link Stripper

Parses clicked and copied hyperlinks to automatically strip tracking parameters, telemetry query strings, and redirect wrappers.

In Action: Strips utm_*, fbclid, and gclid tokens to preserve browsing privacy and clean up URLs.
Architecture

100% Client-Side Evaluation

Operates entirely inside the local browser runtime without routing queries to external analytic engines or logging servers.

In Action: Sub-millisecond evaluation with absolute data isolation and zero dependency on remote uptime.

Support & Frequently Asked Questions

Common questions regarding compatibility, false positives, and extension configurations.

How do I handle false positives?

If a legitimate domain is flagged, you can whitelist it via the popup or report the false positive on our public GitHub issues board.

Does CyberPhishy slow down browsing?

No. The heuristic engine processes URL strings in single-digit milliseconds and operates asynchronously without blocking page rendering.

Where do I report bugs or errors?

You can report false detections, website breakage, or feature ideas directly via our Feedback Page or GitHub tracker.

How are new phishing heuristics updated?

Rule definitions and regex patterns update automatically via lightweight, verified JSON updates over secure HTTPS channels.

Found a mistake or an unflagged phishing link?

Report security threats, false positives, or bugs directly to our public issue tracker.
