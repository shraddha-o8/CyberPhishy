Privacy Policy

Store Compliance

Zero-Log Data Commitment

CyberPhishy was built under the principle of minimal necessary access and complete client-side autonomy.

1. No Data Collection: We do not log, store, monitor, or transmit your browsing history, visited web pages, form data, IP addresses, or personal identifiers.

2. Local Heuristics: All URL decoding, regex validations, and pattern analysis are executed entirely inside your device's browser engine.

3. Minimal Permissions: Permissions requested (such as webNavigation or activeTab) are used exclusively to protect the current active session in real-time.

Support & FAQ

How do I report a false positive?

If a legitimate website is accidentally flagged, you can whitelist the domain directly from the extension popup or submit an issue on our GitHub repo.

Does it slow down browsing?

No. CyberPhishy relies on lightweight, compiled pattern matching that runs in single-digit milliseconds without making blocking external API calls.
